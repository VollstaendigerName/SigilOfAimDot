# SigilOfAimDot

A minimalist dot-style crosshair replacement for Elder Scrolls Online. This addon replaces the default reticle with a clean, customizable dot that dynamically changes color and scale based on your character's state (stealth, combat, swimming, etc.) for better visual feedback and immersion.

Features:
- Replaces the default reticle with a subtle, centered dot

- Dynamic color and scale changes based on player state:

- Stealth: Transparent white

- Combat: Bright red

- Swimming/Falling: Blue or off-white with enlarged scale

- Targeting: Orange-red (attackable) or orange-yellow (interactable)

- Dead/Stunned/Disguised: Black or transparent variants

- Automatically hides in mouse mode and shows in gamepad mode

- Lightweight and performance-friendly with no external dependencies
